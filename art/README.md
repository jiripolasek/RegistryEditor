# Artwork

- [logo.svg](logo.svg): editable vector source for the teal registry cube pyramid, on a transparent 512 by 512 canvas.
- [logo.png](logo.png): transparent 1024 by 1024 bitmap exported from the SVG.
- [logo.ico](logo.ico): Windows icon with 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 pixel frames.
- [screenshot_03.png](screenshot_03.png): the landing-page hero composition with its headline and landscape, using a privacy-reviewed native capture of synthetic Contoso Orion settings and the BatchSize DWORD preview. The app window retains its original pixels and rounded corners.

The README uses the SVG as its canonical logo. Runtime and packaging assets live in `src/Regedit/Assets`.
